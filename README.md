# expense-tracker-system
A console-based Personal Expense Tracker developed using Python and MySQL. The project helps users manage and analyze their expenses efficiently.

1. View Expenses
2. Add Expense
3. Search Expense
4. Update Expense
5. Delete Expense
6. total Expenses
7. highest Expense
8. category Summary
9. monthly Summary
10. expense Count
11. lowest Expense
12. expenses above amount
13. search by category
14. average Expense
15. Exit

 TECHNOLOGIES USED-
 1.Python
 2.MySQL
 3.MySQL Connector/Python

 CONCEPTS USED-
 1.CRUD Operations
 2.SQL Queries
 3.Aggregate Functions (SUM, AVG, MAX, MIN, COUNT)
 4.GROUP BY
5.Database Connectivity
